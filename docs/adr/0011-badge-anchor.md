# ADR-0011: 番号バッジを枠に紐付け、描画時に枠の左上へ置く

- ステータス: 提案中
- 日付: 2026-10-14
- 決定者: Shun（方式は 2026-10-14 に選択済み。この ADR の内容は確認待ち）
- 関連: FR-MCP-08 / NFR-PLAT-05 / [ADR-0005](./0005-rendering-pipeline.md) / [MCP の効果検証](../02-research/mcp-effectiveness.md) / PR #33

## 背景

利用ガイドの見た目の決まりとして、Shun が次のように決めた（2026-10-14）。

- 番号バッジは枠の左上にそろえて置く。
- 番号は枠の中の UI 要素にも周りの UI 要素にも重ねない。

この決まりを MCP の手引き（`GUIDE_LAYOUT_RULES` と、番号の座標の計算式）で渡して 8 回ずつ測った。番号が枠の左上にそろったのは 2 回とも 4/8 だった。エージェントが計算をずらし、番号を枠の角の上に重ねて置いてしまう。一方、吹き出しは `anchor` で枠に紐付けているので、矢印は 8/8 で毎回そろった。

今の `badge` は `x, y, number` だけを持つ。位置は書き手（LLM・利用者）がその都度計算する。枠を動かしても番号は付いてこない。

## 選択肢

### A. `badge` に任意の `anchor` を足し、描画時に置く

- `badge.anchor = { annotationId }`。紐付け先の外接矩形の左上の角の外側に、描画時に置く。
  - 置く位置: 円が枠に重ならないよう、枠の左上の角の完全に外側に置く。円の外接矩形の右下が、枠の角から線の太さの半分だけ左上に離れる位置にする（`x = 枠の x − 直径 − 線の太さ / 2`、`y` も同じ）。既定の大きさ（直径 38、線の太さ 4）なら、枠の角から左上に 40 ずらす。
  - 基準の見た目は、手引きで測った 8 回のうち Shun が最良とした出力（2026-10-14、`/mnt/project-files/mcp-eval/sheets/layout-rules-create.png` の #2）。角に重ねた置き方（同 #3〜#8）は採らない。
  - 画像の外に出るとき: 枠の左の辺の外側に置き、上端を枠にそろえる。
  - 紐付け先が描かれないとき（提案中・非表示・削除済み）: `x, y` の位置に描く。
- 書き手は `x, y` も、計算した位置で保存しておく。`anchor` を知らない古い版でも、ほぼ同じ位置に描かれる。
- エディタの扱い:
  - 枠を動かすと番号も付いてくる。
  - 番号だけをドラッグしたら紐付けを外し、ドラッグした先を `x, y` にする（吹き出しと同じ考え方）。
- 長所:
  - 書き手が座標を計算しなくてよい。どの書き手でも同じ位置になる。
  - 描画は `packages/render` の 1 系統（ADR-0005）なので、Web・拡張・MCP で同じ結果になる。
- 短所:
  - 注釈のスキーマに任意の項目が増える。
  - render・editor・MCP の手引きを変える必要がある。

### B. スキーマは変えず、書き込む側が座標を計算する

- MCP の `harie_edit` などで、番号の位置を枠から計算して `x, y` に書き込む。
- 長所: ファイル形式は変わらない。
- 短所:
  - どの番号がどの枠のものかを、ファイルが知らない。エディタで枠を動かすと番号がずれる。
  - 計算する処理が、MCP とエディタに分かれる。

### C. 手引きだけで続ける（今のまま）

- 長所: 変更がない。
- 短所: そろうのは約半分のまま。

## 決定

A を採る（Shun が 2026-10-14 に選択）。

- 吹き出しの `anchor` で、紐付けると描画側が決めて毎回そろうことは確かめられている。
- 枠と番号の関係がファイルに残るので、エディタで枠を動かしても崩れない。

## 結果（影響）

- 良くなること:
  - 番号の位置が書き手によらずそろう。
  - MCP の手引きは「番号に `anchor` を付ける」だけになり、座標の計算式を渡さなくてよい。
- 悪くなること・受け入れるコスト:
  - `packages/model` のスキーマに任意の項目が増える。項目が増えるだけなので `schemaVersion` は上げない。古い版は `anchor` を無視し、保存されている `x, y` に描く。
  - `document-model.md` の更新が要る。
- 後でやること / 再評価の条件:
  - 実装後、`apps/mcp/eval` で同じ手順のまま再測定し、番号が枠の左上にそろう割合を確かめる。
  - 左上以外に置きたい要望が出たら、`anchor` に `corner` を足すことを検討する。
