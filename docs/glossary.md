# 用語集

| 用語 | 意味 |
|---|---|
| Anoi ファイル | 注釈ドキュメントとベース画像を埋め込んだ JPEG / PNG。見た目は通常の画像 |
| ベース画像 | 注釈を焼き込む前の下地画像。PII 加工は済んでいる。再エンコードせず元のバイト列で保持する |
| レンダリング画像 | ベース画像に注釈を焼き込んだ画像。Anoi ファイルのピクセルそのもの |
| 注釈ドキュメント | 注釈（枠・矢印・テキスト・番号など）の構造化データ（JSON） |
| 注釈（アノテーション） | 画像上に重ねる補足要素 1 つ |
| 記述子 | XMP に書く小さなメタデータ（docId・バージョン・ハッシュ） |
| ペイロード | JUMBF に格納する本体（注釈ドキュメント・ベース画像） |
| JUMBF | ISO/IEC 19566-5 の箱形式。JPEG では APP11 に格納。C2PA と同じ入れ物 |
| XMP | Adobe が策定した XML メタデータ形式。JPEG では APP1 |
| C2PA | 画像の来歴（誰がどう加工したか）を証明する標準。Content Credentials |
| PII | 個人を特定できる情報（氏名・メール・電話番号・住所・顔など） |
| ダミー置換 | PII を同じ種類の架空の値に置き換える加工。画面の意味を保てる |
| DOM スナップショット | Chrome 拡張がキャプチャ時に取得する要素の位置・ラベル・テキスト |
| MCP | Model Context Protocol。AI エージェントから外部ツールを呼ぶための標準プロトコル |
| BYOK | Bring Your Own Key。ユーザー自身の AI API キーを使う方式 |
| ADR | Architecture Decision Record。設計判断とその理由の記録 |
