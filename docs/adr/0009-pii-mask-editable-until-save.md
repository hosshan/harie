# ADR-0009: 個人情報のマスクは保存するまで選んで外せるようにする

- ステータス: 提案中
- 日付: 2026-10-09
- 決定者: Shun（確認待ち）
- 関連: FR-EDIT-05 / FR-PII-04 / NFR-SEC-02 / [ADR-0007](./0007-pii-masking.md)（一部を改める） / PR #22

## 背景

ADR-0007 は、マスクを適用したらベース画像を書き換え、**加工前の画像はファイルにもメモリにも残さない**と決めた。そのため、適用したマスクは編集中でも外せない。

利用者から「誤って隠した範囲を、選択で選んで隠すのをやめられるようにしたい」という要望が出た（2026-10-09、Shun）。ADR-0007 が守りたいのは「公開するファイルから元の個人情報を取り出せないこと」で、編集中のメモリに加工前の画像があることそのものは、ファイルの安全性には影響しない。

## 選択肢

### A. 保存するまでは、加工前の画像をメモリにだけ持つ

- 編集中は、適用したマスクを編集面で選んで外せる（元に戻す／やり直すの対象にもなる）。
- 保存したファイルには加工後の画像だけを入れる。保存した時点で、加工前の画像はメモリからも捨てる。保存後に外したいときは再キャプチャ。
- 長所: 押し間違いをその場で直せる。保存ファイルの安全性（NFR-SEC-02）は今と同じ。
- 短所: 編集中のタブには加工前の画像が残る。保存せずに閉じたときと同じ程度の扱いになる。

### B. マスクを注釈として持ち、保存後も外せる（ADR-0007 の選択肢 A）

- 長所: いつでも外せる。
- 短所: 埋め込んだベース画像から元の個人情報が読める。公開ファイルからの漏えいになるので採らない。

### C. 今のまま（適用前の確認だけ）

- 長所: 実装が最小。
- 短所: 適用後の押し間違いは再キャプチャするしかない。

## 決定

（確認待ち）A を提案する。

## 結果（影響）

- 良くなること: 適用したマスクを、保存するまでは選んで外せる。
- 受け入れるコスト: 保存するまでの間、加工前の画像がメモリに残る。ADR-0007 の「メモリにも残さない」は「保存した時点でメモリからも捨てる」に改める。
- 後でやること: NFR-SEC-02 のテストに「保存後はメモリ上の加工前の画像も捨てている」ことを加える。
