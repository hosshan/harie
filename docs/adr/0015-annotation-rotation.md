# ADR-0015: 注釈の回転を、範囲の中心を軸にした角度 `rotation` として持つ

- ステータス: 提案中
- 日付: 2026-11-12
- 決定者: Shun（2026-11-12 に「要素を回転したい」と依頼。この ADR を含む PR のマージで承認）
- 関連: FR-EDIT-21 / [注釈ドキュメントモデル](../03-design/document-model.md) / [ADR-0004](./0004-image-container-format.md) / [ADR-0005](./0005-rendering-pipeline.md) / [ADR-0011](./0011-badge-anchor.md)

## 背景

画面の斜めの要素を囲みたい、ラベルを傾けて置きたいなど、注釈を回したいという要望がある。いまの注釈は `x, y, w, h` の縦横の四角（矢印は 2 点）でしか位置を持てない。

回した角度は保存した画像に埋め込み、あとで開いても再編集できる必要がある（注釈ドキュメントの一部にする）。注釈ドキュメントは古い版のアプリ（ストア公開済みの Chrome 拡張、npm の @harie/mcp など）でも開かれる。

## 選択肢

### A. 回転できる注釈に任意のフィールド `rotation`（度、時計回り）を足す。軸は回す前の範囲の中心

- 長所: `x, y, w, h` の意味が変わらず、回していない注釈・既存のファイルはそのまま。描画は SVG の `rotate(角度 中心x 中心y)` で包むだけで、エディタの表示と保存画像（resvg）が一致する（ADR-0005）。MCP・AI からも数値 1 つで指定できる。
- 短所: 古い版はスキーマが loose なので `rotation` を知らないフィールドとして残し、回さずに描く（見た目が黙って変わる）。

### B. 回した形を 4 隅の点（多角形）で持つ

- 長所: 古い版がどう扱うかの問題はない（新しい種類として読めない）。
- 短所: 四角・楕円・吹き出しの意味（幅・高さ・角丸・文字の折り返し）が保てず、大きさの変更や文字の編集が難しくなる。新しい種類を足すと古い版では注釈ごと読めなくなる。

### C. `schemaVersion` を上げ、`rotation` を含むファイルは古い版で読めないようにする

- 長所: 古い版で黙って見た目が変わることがない。
- 短所: 回した注釈を 1 つも使っていないファイルまで古い版で開けなくなる（または、回しているときだけ版を上げる仕組みが要る）。ADR-0014 の `head: "start"` と違い、回転は値を足すだけなので古い版を壊すほどの理由がない。

## 決定

A を採る。

- 回せるのは四角（`rect`）・楕円（`ellipse`）・テキスト（`text`）・吹き出し（`callout`）。矢印は端点で向きを変えられるので持たない。番号（丸）は回しても見た目が変わらない。スポットライト・ぼかしは範囲の意味（暗くしない範囲・ぼかす範囲）が縦横の四角を前提にしているので、今回は対象外とする。対象外の種類に `rotation` があっても無視する（`rotationOf`）。
- 単位は度、時計回り（SVG の `rotate` と同じ向き）。省略・0 は回さない。エディタは -180 より大きく 180 以下にそろえて保存し、0° に戻したらフィールドを外す。
- 回転の軸は回す前の範囲（`annotationBox`）の中心。`x, y, w, h` は回す前の値のまま持つ。
- `annotationBounds` は回した形を囲む縦横の四角を返す。範囲選択・重なりの判定・番号の配置（ADR-0011）・吹き出しの配置はこれを使い、回した注釈にも同じ決まりがそのまま効く。
- 吹き出しから紐付け先への線は、回した形を囲む四角どうしで向きを決め、回した側の端を回した縁に寄せる。
- `schemaVersion` は上げない。

## 結果（影響）

- 良くなること: 四角・楕円・テキスト・吹き出しを回して置け、保存後も角度を直せる。MCP・CLI・Skill も同じ `rotation` で指定できる。
- 悪くなること・受け入れるコスト: この変更より前の版では、回した注釈が回さずに描かれる（フィールドは残るので、古い版で保存しても角度は失われない）。回した楕円・吹き出しへの紐付けの線は、縁を四角として近似するので、楕円や角丸の縁から少し離れることがある。
- 後でやること / 再評価の条件: スポットライト・ぼかしを回したい要望が出たら、描画（範囲の切り抜き）と PII 用のマスクとの区別を含めて検討する。複数選んだ注釈をまとめて回すときは、選択全体の中心を軸に位置と `rotation` を変える。
