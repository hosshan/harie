# Harie Skill の評価: 呼び出しの正確さ・コンテキスト効率・品質（FR-MCP-09）

ステータス: 確定（Skill v4 まで） / 最終更新: 2026-11-09

MCP を設定できない環境向けの Harie Skill（`apps/skill`）を、[MCP の効果検証](./mcp-effectiveness.md)と同じお題・同じ採点で、MCP（`@harie/mcp@0.5.1`）と MCP なし（Python で直接描く）と比べた。あわせて、頼み方に応じて Skill が正しく呼ばれるかを確かめた。

## 結論

- **呼ばれるべき頼み方で呼ばれ、関係ない頼み方では呼ばれない。** 12 種の頼み方を 2 回ずつ試して 24/24 正解。注釈を付ける・直す・個人情報を隠す・画像を差し替える・「アップロードした画面キャプチャに吹き出し」は全部 Skill を呼んだ。画像の大きさを調べる・WebP 変換・グレースケール・ファイル一覧・無関係なコード・README 作成では呼ばなかった。
  - ツールの内訳の「Skill 1.0」は手順書を読み込んだ回数。読み込んだあとは Bash から `harie.mjs` を呼ぶので、実際の操作は Bash の回数に入る。全試行で Harie のコマンドで保存していた。
- **品質は MCP と同等か少し上。** v4 の総合は作成 3.9 ± 0.3（MCP 3.8 ± 0.4）、修正 4.6 ± 0.5（MCP 4.3 ± 0.4）。必須の 3 か所・順番・吹き出しの矢印・番号の位置は全試行でそろった。
- **入力トークンは v4（`apply`）で MCP より少なくなったが、MCP なしよりはまだ多い。** 作成の入力トークン合計は v4 が 9.8 万（v3 14.4 万、MCP 11.8 万、MCP なし 2.9 万）、修正は 6.4 万（v3 7.7 万、MCP 5.5 万、MCP なし 5.5 万）。コストは作成 0.126 USD（MCP 0.143、MCP なし 0.045）、修正 0.072 USD（MCP 0.080、MCP なし 0.058）。
- **1 回きりの作成だけを比べると、MCP なし（Python で直接描く）が最も安い。** 差の主因は、Skill の手順書（約 5k トークン）が毎ターン乗ることと、描いた画像を確かめて 1 回直す往復（画像 3 枚 / MCP なし 2.4 枚）。
- **それでも Harie を使う意味は、効率ではなく出力の性質にある。** 番号が枠の左上にそろうのは Skill 8/8 に対し MCP なし 2/8、吹き出しが矢印で枠を指すのは 8/8 に対し 1/8 で、MCP なしは毎回描き方を組み立てるので見た目がそろわない。また、出力が Harie ファイルなので、Web エディタで人が直せ、描画コードや元画像を持たない別の人・別のセッションでも同じ手順で直せる。今回の修正の課題は同じフォルダに元画像が残っていて MCP なしに有利な条件なので、この差は数字に出ていない。

## 残っている課題

- **吹き出しの日本語が語の途中で折り返す**（「選びま／す」「問い合わ／せ」）。採点の減点の主因で、MCP・Web エディタと共通の描画（`packages/render`）の課題。Skill 側では直せない。
- **番号・吹き出しが周りの UI に重なる**（重ならないのは 2〜4/8）。MCP と同じ傾向で、自動配置の改善が要る。
- 1 回きりの作成では MCP なしより約 2.8 倍のコストがかかる。手順書を短くする（使う頻度の低いコマンドの説明を `guide` 側に移す）と、毎ターンの分を減らせる余地がある。

## 計測条件

- お題・採点・集計は [MCP の効果検証](./mcp-effectiveness.md)と同じ（`apps/mcp/eval`。架空の SaaS の通知設定画面、Sonnet 5.5 で実行、Opus 5.5 で採点）。
- Skill の条件は `run.mjs --conditions skill`。`--plugin-dir apps/skill` で Skill だけを読み込み、使えるツールは Bash / Read / Write / Edit / Glob / Skill。どのツールを使うかは指示していない（全試行で Skill が呼ばれた）。Skill は npm の `@harie/mcp@^0.5.1` を `npx` で呼ぶ。
- 呼び出しの正確さは `apps/skill/eval/trigger.mjs`。Bash や Write は選べるが許可しない設定で、最初の 3 回のツール呼び出しまでに Skill が呼ばれたかを見る。
