このページは、Harie（Web エディタ、Chrome 拡張、デスクトップ版、MCP サーバー）が扱うデータについて説明するものです。Harie は個人が開発しているオープンソースのソフトウェアで、ソースコードは GitHub で公開しています。

開発者が受け取るデータはありません

Harie には開発者が運営するサーバーがなく、利用者の画像、注釈、操作の記録、端末の情報を開発者が受け取ることはありません。アカウント登録、アクセス解析、広告、トラッキングのための Cookie も使っていません。

端末の中に保存するデータ

  • 画像と注釈は、利用者が保存したファイル（JPEG / PNG）の中にだけ入ります。
  • Chrome 拡張は、キャプチャした画像と、そのページの要素の位置と文字の一覧を、編集画面に渡すために拡張の中（IndexedDB）に一時的に置きます。24 時間より古いものは次にキャプチャしたときに消します。ページの要素の情報は保存するファイルには入れません。パスワード欄の値は読み取りません。
  • 表示言語、線の太さなどの描画の設定、AI 機能のための API キー（Anthropic のキー、または OpenRouter で接続して発行されたキー）は、そのブラウザ（または拡張）の localStorage にだけ保存します。

外部に送るデータ

AI 機能（補足の提案と個人情報の検出）は任意の機能で、利用者が自分の Anthropic の API キーを登録するか、Web 版で自分の OpenRouter のアカウントで接続したときだけ使えます。ボタンを押すと、送信先を表示して同意を確かめたうえで、画像を Anthropic の Claude API に直接送ります（OpenRouter で接続したときは、OpenRouter を経由して Anthropic の Claude に送ります）。Chrome 拡張でキャプチャした画像では、ページの要素の位置と文字の一覧も一緒に送ります。送ったデータは、利用者と Anthropic（OpenRouter で接続したときは OpenRouter も）との契約と Anthropic のプライバシーポリシー、 OpenRouter のプライバシーポリシーに従って扱われます。開発者を経由することはありません。

OpenRouter での接続では、OpenRouter の許可の画面から戻ったときに受け取る一時的なコードを、お使いのブラウザから OpenRouter に送ってキーに換えます。このキーもブラウザの中にだけ保存し、開発者には送りません。

AI 機能を使わなければ、Harie が画像やページの内容を外部に送ることはありません。

Chrome 拡張の権限

  • activeTab: ツールバーのボタンかショートカットを押したタブだけを、そのときに限ってキャプチャするために使います。インストール時に常時のサイトへのアクセス権は求めません。
  • scripting: 押したタブに、範囲や要素を選ぶための表示と、ページの要素の位置と文字を読み取る処理を、その都度入れるために使います。
  • downloads: 注釈を付けた画像を、ダウンロードフォルダに保存するために使います。
  • 任意のサイトへのアクセス（GitHub、またはすべてのサイト）: ポップアップで「GitHub で注釈データを文字で表示する」「ほかのサイトでも画像から編集を開く」をオンにしたときだけ求めます。許可したサイトでだけ、ページ上の Harie 画像を読み、注釈の文字を表示したり、拡張のエディタで開いたりするために使います。読んだ画像はどこにも送りません。オフにすると権限を返します。

Chrome 拡張が扱うデータの利用は、Limited Use の要件を含む Chrome ウェブストアのユーザーデータに関するポリシーに従います。データを第三者に販売したり、上に書いた目的のほかに使ったりすることはありません。

このサイトについて

このサイトと Web エディタは GitHub Pages で配信しています。アクセスの記録は GitHub が GitHub のプライバシーステートメントに従って扱います。紹介ページ（このページを含む）は Google Fonts から文字の形を読み込みます。Web エディタは外部からフォントを読み込みません。
