Capture, anote e guarde.

O Harie cuida de tudo, da primeira captura ao arquivo salvo.

  1. 1

    Capturar

    Com a extensão para Chrome, você captura a página em que está e abre direto no editor. Escolha a área visível, uma região que você arrasta ou um único elemento, como um botão.

  2. 2

    Anotar

    Explique com caixas, setas, números, balões e destaques. Diga ao Harie o que você quer explicar, e a IA sugere caixas numeradas com as legendas.

  3. 3

    Guardar

    O Harie salva um JPEG ou PNG comum. Você pode colar como está na sua central de ajuda, e quem abrir depois ainda consegue editar as anotações.

Abra uma captura de tela, desenhe caixas e clique em “Adicionar números e balões” para adicionar os números e os balões de uma vez. Depois é só digitar o texto dos balões.

Abra uma imagem salva com o Harie e as caixas e os balões voltam como estavam. Quando o texto da interface mudar, clique duas vezes no balão, corrija e salve de novo.

Selecione nomes e endereços de e-mail e troque-os por texto fictício. A tela mantém a aparência, então ainda dá para entender o que é, e os valores originais não ficam na imagem.

Por que continua editável

Uma imagem guarda a tela original e as anotações.

Uma imagem salva pelo Harie leva a captura original e os dados das anotações junto com a imagem que você vê. Outros apps e navegadores simplesmente mostram uma imagem normal.

Abra no Harie e você pode mover ou reescrever cada caixa e legenda. Não é preciso guardar um arquivo de projeto separado, e quem recebe a imagem pode abri-la e corrigi-la.

Salvar de novo nunca recomprime a captura original, então a qualidade se mantém não importa quantas vezes você edite. A especificação do formato é pública (em japonês).

AI

Deixe a IA ajudar a decidir o que apontar.

Anotações sugeridas

Escreva algo como “Explique como configurar as notificações do Slack”, e a IA sugere onde ficam as caixas e o que elas dizem. Você pode aceitar, rejeitar ou editar cada sugestão. Nas capturas da extensão para Chrome, as caixas se alinham aos elementos reais da página.

Conecte-se com o OpenRouter ou use sua própria chave de API da Anthropic. O Harie sempre pergunta antes de enviar uma imagem, e sua chave nunca sai deste navegador.

Edite pelo Claude (Skill e MCP)

Adicione a Skill do Harie ao claude.ai, anexe uma captura ao chat e peça ao Claude para adicionar ou corrigir anotações. Com o Claude Code ou o Claude Desktop no seu computador, o servidor @harie/mcp trabalha diretamente com as imagens de uma pasta. Quando o texto da interface muda, você pode atualizar de uma vez todas as imagens afetadas.

Dados pessoais

Tire os dados pessoais e mantenha o sentido.

Substitua nomes, endereços de e-mail e números de telefone por valores fictícios. Diferente de um desfoque, assim os leitores ainda entendem que tipo de tela estão vendo. Se preferir, também há preenchimento, mosaico e desfoque.

A ocultação é aplicada à própria imagem original, então não pode ser desfeita. Isso também significa que os valores originais não vão junto com o arquivo quando você o compartilha.

Como configurar

Integrações com IA

Peça à IA para anotar por você.

Basta pedir ao Claude, e ele adiciona anotações às suas imagens do Harie ou corrige o texto delas. Use a Skill no claude.ai e em sessões na nuvem, ou o servidor MCP com o Claude Code, o Claude Desktop e o app desktop do ChatGPT no seu computador. De qualquer forma, você obtém o mesmo arquivo.

O mascaramento de dados pessoais não pode ser desfeito, então o Harie só salva depois que você confirma.

Funciona nos chats e projetos do claude.ai e no Claude Code on the web. Não é preciso instalar nada no computador: anexe uma captura ao chat e peça as anotações.

  1. Baixe harie.skill nas releases do GitHub.
  2. No claude.ai, vá em Configurações → Recursos e ative Execução de código e criação de arquivos.
  3. Na mesma página, envie harie.skill em Skills.

As Skills que você adiciona à sua conta também funcionam no Claude Code on the web. No Claude Code, você também pode instalá-la como plugin com estes comandos.

/plugin marketplace add hosshan/harie
/plugin install harie@harie
  • A Skill busca @harie/mcp no npm e o executa dentro da conversa, então o desenho e o salvamento funcionam exatamente como no MCP.
  • Nos planos Team e Enterprise, um administrador precisa permitir Skills e a execução de código.
Guia de instalação detalhado (GitHub, em japonês)

Registre o servidor @harie/mcp em um app do seu computador, e ele poderá abrir e corrigir imagens de uma pasta da sua máquina.

Execute este comando no terminal.

claude mcp add harie -- npx -y @harie/mcp --root ~/Pictures/guides

Adicione isto a claude_desktop_config.json e reinicie o Claude Desktop. Troque a pasta pelo seu próprio caminho.

{
  "mcpServers": {
    "harie": {
      "command": "npx",
      "args": ["-y", "@harie/mcp", "--root", "/Users/you/Pictures/guides"]
    }
  }
}

Funciona no app de desktop do ChatGPT. Adicione isto a ~/.codex/config.toml e reinicie o app. A mesma configuração é compartilhada com o Codex CLI e a extensão para IDE. Você também pode adicionar o mesmo comando como servidor STDIO em servidores MCP, nas configurações do app.

[mcp_servers.harie]
command = "npx"
args = ["-y", "@harie/mcp", "--root", "/Users/you/Pictures/guides"]

O ChatGPT na web não consegue se conectar a servidores MCP que rodam no seu computador.

  • Requer Node.js 22 ou posterior. O servidor roda a partir do npm com npx, então não há mais nada para instalar.
  • Aponte --root para a pasta que guarda suas imagens. O servidor só pode ler e gravar dentro dessa pasta.

Perguntas frequentes

O que é o Harie?

O Harie é uma ferramenta para adicionar caixas, números, balões e setas às capturas de tela da documentação de ajuda e dos guias de uso de um SaaS. Ele salva um JPEG ou PNG comum e, quando você abre essa imagem no Harie de novo, todas as anotações continuam editáveis.

Outros apps e sites conseguem exibir as imagens salvas?

Sim. O Harie salva um JPEG ou PNG comum, então você pode colá-lo como está em páginas de ajuda, chats ou documentos. A captura original e os dados das anotações ficam nos metadados da imagem, e só o Harie os usa.

Posso editar imagens de guia feitas por outra pessoa?

Sim, desde que tenham sido salvas com o Harie. Abra no Harie a imagem que você recebeu e você poderá mover ou reescrever cada caixa e nota. Não é preciso arquivo de projeto nem conta.

Qual a diferença entre o Harie e ferramentas como Snagit ou Scribe?

A própria imagem exportada continua editável. Apps de captura de tela guardam as anotações editáveis em arquivos de projeto próprios, que ficam com quem os criou. Serviços de criação de guias só permitem editar dentro das próprias contas. O Harie guarda a captura original e as anotações dentro do JPEG ou PNG, então qualquer pessoa que tenha a imagem da sua página de ajuda pode abri-la e editá-la. O Harie não gera guias passo a passo a partir de ações gravadas.

O Harie é pago?

Não. O Harie é gratuito, de código aberto sob a Licença MIT e não exige cadastro. Só as sugestões de IA precisam da sua própria chave de API da Anthropic ou de uma conta no OpenRouter, e você paga a esses serviços pelo que usar.

Minhas imagens são enviadas para um servidor?

Não. As imagens são processadas no seu navegador ou dispositivo, e o desenvolvedor nunca as recebe. Só quando você usa os recursos de IA o Harie envia a imagem, depois de perguntar, diretamente para a API do Claude da Anthropic (pelo OpenRouter, se você se conectou com o OpenRouter).

Posso esconder dados pessoais em uma captura de tela?

Sim. Você pode substituir nomes, endereços de e-mail e números de telefone por valores fictícios, ou usar preenchimento, mosaico ou desfoque. A alteração é aplicada à própria imagem original, então não pode ser desfeita, e os valores originais não ficam no arquivo que você compartilha.

Onde posso usar o Harie?

Há um editor web que roda no navegador, uma extensão do Chrome que captura a página em que você está, uma Skill para o claude.ai e outros ambientes, e um servidor MCP para agentes de IA. O app desktop para macOS e Windows ainda não é distribuído, mas você pode compilá-lo a partir do código-fonte.

Agentes de IA como o Claude podem adicionar anotações?

Sim. Adicione a Skill (harie.skill) ao claude.ai e o Claude poderá anotar as capturas que você anexar ao chat. Registre o servidor MCP @harie/mcp no Claude Code ou no Claude Desktop e ele poderá abrir imagens da pasta que você escolher, adicionar anotações e atualizar o texto.
