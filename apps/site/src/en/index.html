Capture. Annotate. Keep.

One tool from capture to saved file.

  1. 1

    Capture

    Grab the page you're on with the Chrome extension and open it straight in the editor. Capture the visible area, a region you drag, or a single element like a button.

  2. 2

    Annotate

    Boxes, arrows, numbers, callouts and spotlights. Describe what you want to explain and AI drafts numbered boxes and captions.

  3. 3

    Keep

    Save as a regular JPEG or PNG. Paste it into your help center as is, and anyone who opens it later can still edit the annotations.

How it stays editable

One image holds the original screen and the annotations.

An image saved by Harie carries the original screenshot and the annotation data alongside the picture you see. Other apps and browsers simply show a normal image.

Open it in Harie and you can move or rewrite every box and caption, one by one. There's no separate project file to keep track of. Whoever receives the image can open it and fix it.

Saving again never recompresses the original screenshot, so quality holds up however many times you edit. The file format spec is public (in Japanese).

AI

Decide where and what, with AI.

Suggested annotations

Write something like "Explain how to set up Slack notifications" and AI drafts where the boxes go and what they say. Accept, reject or edit each suggestion. On screenshots from the Chrome extension, boxes line up with the page's actual elements.

Uses your own Anthropic API key. Harie asks before sending an image, and the key stays in this browser.

Edit from Claude (MCP)

Register the @harie/mcp server, then just ask Claude Code or Claude Desktop to add or fix annotations. When UI text changes, you can update many images in one go.

Personal data

Remove personal data, keep the meaning.

Replace names, email addresses and phone numbers with dummy values. Readers can still tell what kind of screen it is, which blurring can't do. Fill, mosaic and blur are available too.

Masking is applied to the original image itself and can't be undone. When you share the file, the original values aren't hiding inside it.
