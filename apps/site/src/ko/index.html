브라우저에서 쓰기

도움말 가이드를 쓰는 분들께

평범한 이미지인데,
언제든 다시 고칠 수 있다.

가이드에 쓰는 스크린샷에 박스, 번호, 설명을 붙이세요. Harie는 어디에나 붙여넣을 수 있는 일반 JPEG 또는 PNG로 저장합니다. 나중에 Harie에서 열어도 박스와 설명을 모두 그대로 고칠 수 있습니다.

브라우저에서 쓰기 Chrome에 추가

무료 오픈 소스(MIT)이며 소스는 GitHub에 공개되어 있습니다. 브라우저 버전은 설치나 계정 없이 쓸 수 있고, 편집기는 한국어, 영어, 일본어, 중국어, 스페인어, 포르투갈어 등 7개 언어를 지원합니다.

가이드용 스크린샷은 생각보다 손이 많이 갑니다.

  • 어디를 강조할지 매번 고민합니다

    게다가 팀원마다 조금씩 다르게 만듭니다.

    어디를 감싸고 뭐라고 쓸지 AI가 초안을 만듭니다

  • 이미지마다 같은 작업을 반복합니다

    캡처하고, 열고, 주석을 달고, 내보내고, 다음 이미지에서 또 처음부터 반복합니다.

    캡처한 페이지에 바로 주석을 답니다

  • 문구 하나가 바뀌면 이미지를 다시 만들어야 합니다

    버튼 이름이 바뀌면 스크린샷을 처음부터 다시 만들어야 합니다. 팀원이 만든 이미지라면 원본 파일이 남아 있지 않을 수도 있습니다.

    이미지를 열면 누구나 그 자리에서 고칠 수 있습니다

  • 고객 데이터가 화면에 찍힙니다

    실제 서비스 화면에는 실명과 이메일 주소가 가득합니다.

    되돌릴 수 없는 더미 값으로 바꿉니다

캡처하고, 주석을 달고, 남겨 둡니다.

처음 캡처부터 저장한 파일까지 Harie 하나로 해결합니다.

  1. 1

    캡처

    Chrome 확장 프로그램으로 보고 있는 페이지를 캡처해 바로 편집기에서 열 수 있습니다. 보이는 영역, 드래그한 영역, 버튼 같은 요소 하나를 골라 찍을 수 있습니다.

  2. 2

    주석 달기

    박스, 화살표, 번호, 말풍선, 스포트라이트로 설명합니다. 설명하고 싶은 내용을 알려 주면 AI가 번호가 붙은 박스와 설명의 초안을 만들어 줍니다.

  3. 3

    보관

    Harie는 일반 JPEG 또는 PNG로 저장합니다. 도움말 센터에 그대로 붙여넣을 수 있고, 나중에 연 사람도 주석을 고칠 수 있습니다.

스크린샷을 열고 상자를 그린 뒤 “번호와 말풍선 붙이기”를 누르면 번호와 말풍선이 한 번에 붙습니다. 그다음 말풍선의 문구만 입력하면 됩니다.

Harie로 저장한 이미지를 열면 상자와 말풍선이 그대로 돌아옵니다. 화면의 문구가 바뀌면 말풍선을 더블클릭해 고치고 다시 저장하면 됩니다.

이름이나 이메일 주소를 골라 더미 문자로 바꿉니다. 화면의 모양은 그대로라서 무엇인지 알아볼 수 있고, 원래 값은 이미지에 남지 않습니다.

계속 고칠 수 있는 이유

이미지 한 장에 원래 화면과 주석이 함께 들어 있습니다.

Harie로 저장한 이미지에는 눈에 보이는 그림과 함께 원본 스크린샷과 주석 데이터가 들어 있습니다. 다른 앱이나 브라우저에서는 평범한 이미지로 보입니다.

Harie에서 열면 박스와 설명을 하나씩 옮기거나 다시 쓸 수 있습니다. 프로젝트 파일을 따로 보관할 필요가 없고, 이미지를 받은 사람도 열어서 고칠 수 있습니다.

다시 저장해도 원본 스크린샷은 재압축하지 않으므로 몇 번을 고쳐도 화질이 떨어지지 않습니다. 파일 형식 사양 은 공개되어 있습니다(일본어).

가이드용 스크린샷을 만드는 방법
이미지 편집기에서 내보내기 가이드 제작 서비스 Harie
도움말 센터에 그대로 붙여넣기 가능 서비스에서 내보내기 가능
공개한 뒤에 글자 고치기 프로젝트 파일이 남아 있다면 서비스 안에서 가능, 이미지를 열기만 하면 됨
만든 사람이 아니어도 고치기 프로젝트 파일을 넘겨준다면 같은 요금제의 멤버 가능, 이미지를 보내기만 하면 됨
계정이나 구독 없이 사용 도구에 따라 다름 필요 가능

AI

어디를 짚을지, AI와 함께 정하세요.

주석 제안

‘Slack 알림 설정 방법을 설명하고 싶다’처럼 쓰면, 어디를 감싸고 뭐라고 쓸지 AI가 초안을 만듭니다. 제안은 하나씩 채택하거나 거절하거나 고칠 수 있습니다. Chrome 확장 프로그램으로 찍은 이미지라면 박스가 페이지의 실제 요소 위치에 맞춰집니다.

OpenRouter로 연결하거나 본인의 Anthropic API 키를 사용합니다. 이미지를 보내기 전에는 항상 확인을 받으며, 키는 이 브라우저 밖으로 나가지 않습니다.

Claude에서 바로 편집(Skill과 MCP)

claude.ai에 Harie Skill을 추가해 두면, 채팅에 스크린샷을 첨부하고 요청하기만 해도 Claude가 주석을 붙이거나 고칩니다. 내 컴퓨터의 Claude Code나 Claude Desktop에서는 @harie/mcp 서버로 폴더의 이미지를 직접 다룹니다. UI 문구가 바뀌어도 관련 이미지를 한 번에 고칠 수 있습니다.

개인정보

개인정보는 지우고, 의미는 남깁니다.

이름, 이메일 주소, 전화번호를 더미 값으로 바꿉니다. 흐림과 달리 어떤 화면인지는 그대로 알 수 있습니다. 원한다면 채우기, 모자이크, 흐림도 쓸 수 있습니다.

마스킹은 원본 이미지 자체에 적용하므로 되돌릴 수 없습니다. 그래서 파일을 공유해도 원래 값이 함께 전달되지 않습니다.

AI 연동

AI에게 주석을 맡기세요.

Claude에게 요청하기만 하면 Harie 이미지에 주석을 붙이거나 문구를 고칩니다. claude.ai나 클라우드 세션에서는 Skill을, 내 컴퓨터의 Claude Code, Claude Desktop, ChatGPT 데스크톱 앱에서는 MCP 서버를 사용합니다. 어느 쪽으로 만들어도 같은 파일이 됩니다.

개인정보 처리는 되돌릴 수 없으므로, Harie는 확인을 받은 뒤에만 저장합니다.

claude.ai의 채팅과 프로젝트, Claude Code on the web에서 사용할 수 있습니다. 컴퓨터에 아무것도 설치하지 않고, 채팅에 스크린샷을 첨부해 주석을 요청하면 됩니다.

  1. GitHub 릴리스에서 harie.skill 파일을 다운로드합니다.
  2. claude.ai의 설정 → 기능에서 '코드 실행 및 파일 생성'을 켭니다.
  3. 같은 화면의 스킬에서 harie.skill 파일을 업로드합니다.

계정에 추가한 Skill은 Claude Code on the web 세션에서도 사용할 수 있습니다. Claude Code에서는 다음 명령으로 플러그인으로 설치할 수도 있습니다.

/plugin marketplace add hosshan/harie
/plugin install harie@harie
  • Skill은 대화 안에서 npm의 @harie/mcp 패키지를 받아 실행하므로, 그리기와 저장은 MCP와 똑같습니다.
  • Team이나 Enterprise 플랜에서는 관리자가 스킬과 코드 실행을 허용해야 합니다.
자세한 설치 방법(GitHub, 일본어)

내 컴퓨터의 앱에 @harie/mcp 서버를 등록하면, 컴퓨터 안 폴더의 이미지를 직접 열어 고칠 수 있습니다.

터미널에서 이 명령을 실행하세요.

claude mcp add harie -- npx -y @harie/mcp --root ~/Pictures/guides

claude_desktop_config.json 에 이 설정을 추가하고 Claude Desktop을 다시 시작하세요. 폴더는 자신의 경로로 바꿔 주세요.

{
  "mcpServers": {
    "harie": {
      "command": "npx",
      "args": ["-y", "@harie/mcp", "--root", "/Users/you/Pictures/guides"]
    }
  }
}

ChatGPT 데스크톱 앱에서 쓸 수 있습니다. ~/.codex/config.toml 에 이 설정을 추가하고 앱을 다시 시작하세요. 이 설정은 Codex CLI와 IDE 확장 프로그램에서도 함께 씁니다. 앱 설정의 MCP 서버 화면에서 같은 명령을 STDIO 서버로 추가할 수도 있습니다.

[mcp_servers.harie]
command = "npx"
args = ["-y", "@harie/mcp", "--root", "/Users/you/Pictures/guides"]

웹의 ChatGPT는 내 컴퓨터에서 실행 중인 MCP 서버에 연결할 수 없습니다.

  • Node.js 22 이상이 필요합니다. 서버는 npm에서 npx로 실행되므로 따로 설치할 것은 없습니다.
  • --root 에 이미지가 있는 폴더를 지정하세요. 서버는 그 폴더 안에서만 읽고 쓸 수 있습니다.

자주 묻는 질문

Harie는 무엇인가요?

Harie는 SaaS 도움말 문서와 사용 가이드의 스크린샷에 박스, 번호, 말풍선, 화살표를 붙이는 도구입니다. 일반 JPEG 또는 PNG로 저장하며, 그 이미지를 Harie에서 다시 열면 모든 주석을 그대로 고칠 수 있습니다.

저장한 이미지를 다른 앱이나 웹사이트에서도 표시할 수 있나요?

네. Harie는 일반 JPEG 또는 PNG로 저장하므로 도움말 페이지, 채팅, 문서에 그대로 붙여넣을 수 있습니다. 원본 스크린샷과 주석 데이터는 이미지의 메타데이터에 들어 있고, 이를 쓰는 것은 Harie뿐입니다.

다른 사람이 만든 가이드 이미지도 고칠 수 있나요?

네, Harie로 저장한 이미지라면 가능합니다. 받은 이미지를 Harie에서 열면 박스와 설명을 하나씩 옮기거나 다시 쓸 수 있습니다. 프로젝트 파일이나 계정은 필요 없습니다.

Snagit이나 Scribe 같은 도구와 무엇이 다른가요?

내보낸 이미지 자체를 계속 고칠 수 있다는 점입니다. 스크린샷 앱은 고칠 수 있는 주석을 자체 프로젝트 파일에 두기 때문에 만든 사람에게만 남습니다. 가이드 제작 서비스는 해당 서비스의 계정 안에서만 고칠 수 있습니다. Harie는 원본 스크린샷과 주석을 JPEG 또는 PNG 안에 담으므로, 도움말 페이지의 이미지를 가진 사람이라면 누구나 열어서 고칠 수 있습니다. 녹화한 조작에서 단계별 가이드를 자동으로 만드는 기능은 없습니다.

Harie는 유료인가요?

아니요. Harie는 무료이고 MIT 라이선스의 오픈 소스이며, 가입도 필요 없습니다. AI 제안을 쓸 때만 본인의 Anthropic API 키나 OpenRouter 계정이 필요하고, 사용한 만큼 해당 서비스에 비용을 냅니다.

이미지가 서버로 전송되나요?

아니요. 이미지는 브라우저나 기기 안에서 처리되며 개발자에게 전달되지 않습니다. AI 기능을 쓸 때만 확인을 받은 뒤 이미지를 Anthropic의 Claude API로 직접 보냅니다(OpenRouter로 연결했다면 OpenRouter를 거칩니다).

스크린샷 속 개인정보를 가릴 수 있나요?

네. 이름, 이메일 주소, 전화번호를 더미 값으로 바꾸거나 채우기, 모자이크, 흐림으로 가릴 수 있습니다. 원본 이미지 자체에 적용하므로 되돌릴 수 없고, 공유하는 파일에 원래 값이 남지 않습니다.

Harie는 어디에서 쓸 수 있나요?

브라우저에서 동작하는 웹 편집기, 보고 있는 페이지를 캡처하는 Chrome 확장 프로그램, claude.ai 등에 추가하는 Skill, AI 에이전트용 MCP 서버가 있습니다. macOS와 Windows용 데스크톱 앱은 아직 배포하지 않지만, 소스에서 빌드해 사용할 수 있습니다.

Claude 같은 AI 에이전트가 주석을 붙일 수 있나요?

네. claude.ai에 Skill(harie.skill)을 추가하면 채팅에 첨부한 스크린샷에 Claude가 주석을 붙입니다. Claude Code나 Claude Desktop에 MCP 서버 @harie/mcp를 등록하면 지정한 폴더의 이미지를 열어 주석을 추가하고 문구를 고칠 수 있습니다.
