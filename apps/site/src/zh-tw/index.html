為什麼還能編輯

一張圖片裡，同時放著原始畫面和註解。

用 Harie 存的圖片，除了你看到的畫面之外，還帶著原始截圖和註解資料。其他 App 和瀏覽器只會把它當成一般圖片顯示。

用 Harie 開啟，就能移動或改寫每個方框和說明。不需要另外保留專案檔，收到圖片的人也能開啟並修改。

重新存檔時不會再次壓縮原始截圖，所以不管修改幾次，畫質都不會變差。 檔案格式規格 已公開（日文）。

AI

讓 AI 幫你決定要標出哪裡。

建議的註解

輸入像是「說明如何設定 Slack 通知」，AI 就會草擬方框的位置和說明文字。每個建議都可以採用、拒絕或修改。若是 Chrome 擴充功能擷取的截圖，方框會對齊頁面上實際的元素。

可以用 OpenRouter 連線，或使用你自己的 Anthropic API 金鑰。Harie 傳送圖片前一定會先詢問，金鑰也不會離開這個瀏覽器。

從 Claude 編輯（MCP）

註冊 @harie/mcp 伺服器後，就能請 Claude Code 或 Claude Desktop 幫你加上或修改註解。畫面文字改了的時候，也能一次更新所有相關的圖片。

個人資料

去掉個人資料，保留畫面的意思。

把姓名、電子郵件地址和電話號碼換成假資料。和模糊處理不同，讀者仍然看得出這是什麼樣的畫面。也可以選擇塗滿、馬賽克或模糊。

遮蔽會直接套用在原始圖片上，無法復原。也因此，分享檔案時原本的資料不會跟著傳出去。

MCP

讓 Claude 這類 AI 代理讀寫你指定資料夾裡的圖片。

設定方式

開始使用 MCP

請 Claude 幫你標註。

註冊 @harie/mcp 伺服器後，Claude Code、Claude Desktop 和 ChatGPT 桌面 App 就能開啟 Harie 圖片，加上或修改註解。

在終端機執行這個指令。

claude mcp add harie -- npx -y @harie/mcp --root ~/Pictures/guides

把這段設定加到 claude_desktop_config.json ，然後重新啟動 Claude Desktop。請把資料夾換成你自己的路徑。

{
  "mcpServers": {
    "harie": {
      "command": "npx",
      "args": ["-y", "@harie/mcp", "--root", "/Users/you/Pictures/guides"]
    }
  }
}

可在 ChatGPT 桌面 App 使用。把這段設定加到 ~/.codex/config.toml ，然後重新啟動 App。這份設定也會由 Codex CLI 和 IDE 擴充功能共用。也可以在 App 設定的 MCP 伺服器畫面，把同一個指令新增為 STDIO 伺服器。

[mcp_servers.harie]
command = "npx"
args = ["-y", "@harie/mcp", "--root", "/Users/you/Pictures/guides"]

網頁版 ChatGPT 無法連線到在你電腦上執行的 MCP 伺服器。

  • 需要 Node.js 22 以上版本。伺服器透過 npm 的 npx執行，不需要另外安裝。
  • 把 --root 指向存放圖片的資料夾。伺服器只能在這個資料夾內讀寫。

常見問題

Harie 是什麼？

Harie 是一個為 SaaS 說明文件和使用指南的螢幕截圖加上方框、編號、說明框和箭頭的工具。它會存成一般的 JPEG 或 PNG，之後在 Harie 重新開啟這張圖片時，所有註解都還能編輯。

存好的圖片能在其他 App 或網站上顯示嗎？

可以。Harie 存成一般的 JPEG 或 PNG，所以能直接貼到說明頁面、聊天或文件裡。原始截圖和註解資料放在圖片的中繼資料裡，只有 Harie 會用到。

別人做的說明圖片，我也能修改嗎？

可以，只要是用 Harie 存的圖片就行。在 Harie 開啟收到的圖片，就能移動或改寫每個方框和說明。不需要專案檔，也不需要帳號。

Harie 和 Snagit、Scribe 這類工具有什麼不同？

匯出的圖片本身就能繼續編輯。截圖 App 會把可編輯的註解存在自家的專案檔裡，而專案檔只留在製作者手上。製作指南的服務則只能在自家帳號裡編輯。Harie 把原始截圖和註解存進 JPEG 或 PNG 裡，所以任何拿到說明頁面上那張圖片的人，都能開啟並修改。Harie 不會從錄下的操作自動產生步驟指南。

Harie 要付費嗎？

不用。Harie 免費、以 MIT 授權開放原始碼，也不需要註冊。只有 AI 建議需要你自己的 Anthropic API 金鑰或 OpenRouter 帳號，費用依用量付給這些服務。

我的圖片會被傳到伺服器嗎？

不會。圖片在你的瀏覽器或裝置上處理，開發者不會收到。只有在使用 AI 功能時，Harie 才會先詢問你，再把圖片直接送到 Anthropic 的 Claude API（若用 OpenRouter 連線，則經由 OpenRouter）。

可以把截圖裡的個人資料藏起來嗎？

可以。你可以把姓名、電子郵件地址和電話號碼換成假資料，也可以用塗滿、馬賽克或模糊處理。這些處理會直接套用在原始圖片上，無法復原，原本的資料也不會留在分享出去的檔案裡。

Harie 能在哪裡使用？

有在瀏覽器執行的網頁版編輯器、擷取目前頁面的 Chrome 擴充功能，以及給 AI 代理使用的 MCP 伺服器。macOS 和 Windows 的桌面 App 目前還沒有發布，但可以從原始碼自行建置。

Claude 這類 AI 代理也能加上註解嗎？

可以。把 MCP 伺服器 @harie/mcp 註冊到 Claude Code 或 Claude Desktop，它就能開啟你指定資料夾裡的圖片、加上註解並修改文字。
