ガイドの画像づくりは、手間が多い。

  • どこを囲み、何と書くか毎回迷う人によって書き方もばらばらになります。
  • 画像の数だけ同じ作業撮る、開く、書く、書き出すを繰り返します。
  • 文言 1 つで作り直しボタンの名前が変わっただけで、画像を作り直します。
  • 前任者の画像を直せない元のデータがどこにあるか分かりません。
  • 個人情報が映り込む本番の画面には、お客さまの名前やメールが並びます。

撮って、補って、残す。

取得から保存までを 1 本でつなぎます。

  1. 1

    撮る

    Chrome 拡張で表示中のページを撮って、そのままエディタへ。見えている範囲・ドラッグした範囲・ボタンなどの要素を選べます。

  2. 2

    補う

    枠・矢印・番号・吹き出し・スポットライト。説明したいことを書けば、AI が番号付きの枠と説明文を下書きします。

  3. 3

    残す

    保存はふつうの JPEG / PNG。ヘルプページにそのまま貼れて、あとから誰が開いても注釈を直せます。

保存したあとも直せる仕組み

1 枚の画像に、元の画面と注釈が入っている。

Harie で保存した画像には、見るための画像と一緒に、元のスクリーンショットと注釈のデータが入っています。ほかのアプリやブラウザでは、ふつうの画像として表示されます。

Harie で開くと、枠も文字も 1 つずつ動かしたり書き換えたりできます。プロジェクトファイルを別に残す必要はありません。画像を受け取った人が、そのまま開いて直せます。

保存し直しても元のスクリーンショットは再圧縮しないので、何度直しても画質は落ちません。ファイル形式の仕様も公開しています。

AI

「どこに、何を」を、AI と決める。

補足の提案

「Slack 通知の設定方法を説明したい」のように書くと、AI が囲む場所と説明文を下書きします。下書きは 1 つずつ採用・却下・修正できます。Chrome 拡張で撮った画像は、ページの要素の位置に枠を合わせます。

Anthropic の API キーを設定して使います。画像を送る前に確認を出し、キーはこのブラウザの中にだけ保存します。

Claude から直接編集（MCP）

MCP サーバー @harie/mcp を登録すると、Claude Code や Claude Desktop に頼むだけで注釈を付けたり直したりできます。UI の文言が変わったときも、まとめて直せます。

個人情報

何の画面かは伝わるまま、個人情報だけ消す。

氏名・メール・電話番号などを、ダミーの値に置き換えられます。ぼかすより、どんな項目が並ぶ画面なのかが読み手に伝わります。塗りつぶし・モザイク・ぼかしも選べます。

加工は元の画像に直接かけるので、元に戻せません。ファイルを人に渡しても、加工前の値は中に残りません。
