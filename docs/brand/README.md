# ブランド（ロゴと配色）

ステータス: 確定 / 最終更新: 2026-10-14

## ロゴ

| ファイル | 用途 |
|---|---|
| [harie-symbol.svg](harie-symbol.svg) | シンボル（背景なし）。Web のタブアイコン、Chrome 拡張のアイコン、ヘッダー |
| [harie-app-icon.svg](harie-app-icon.svg) | クリーム色の背景付き。PWA・ホーム画面のアイコン（maskable の安全域に収まる） |

- 形: 薄い黄の角丸四角（画像・紙）に、黄土色の丸（貼ったもの）を重ね、重なった部分を濃くする。「貼り絵」を抽象化した形。
- 比率: 四角の一辺と丸の直径は 1:√2（大和比）。丸の縁は四角の辺を √2:1 の位置で分ける。
- ワードマークは「Harie」をシンボルの右に置く。シンボルだけで使ってよい。
- アイコン PNG は `pnpm brand:icons`（[scripts/brand-icons.mjs](../../scripts/brand-icons.mjs)）で SVG から作る。ロゴを変えたら作り直してコミットする。

## 配色

| 名前 | 値 | 使い方 |
|---|---|---|
| メイン（黄土） | `#D4A72C` | 主ボタンの背景、選択中の状態、ロゴの丸 |
| ディープ | `#B0861A` | 選択枠・フォーカスの線、ロゴの重なり |
| ライト | `#EBD08A` | ロゴの四角 |
| 文字用の濃い黄 | `#86650F` | 白背景に載せる黄色系の文字（コントラスト 5.4:1） |
| インク | `#2B2620` | 本文の文字、黄土色の上の文字（`#D4A72C` 上で 6.7:1） |
| サブの文字 | `#7A7064` | 補足の文字（白背景で 4.9:1） |
| クリーム | `#FBF6E9` | 面の背景（編集面の下地、コード表示など） |
| 線 | `#E6DCC6` | 枠線・区切り線 |

- 黄土色（`#D4A72C`）は白背景の文字に使わない（コントラスト不足）。文字には `#86650F` を使う。
- CSS では Web（`apps/web/src/styles.css`）が `--accent` など、エディタ（`packages/editor/src/editor.css`）が `--harie-accent` などの変数で持つ。
- 注釈の色（赤・橙・緑・青・黒）、AI 提案（紫）、PII 加工（赤）は意味を持つ色なので、ブランド配色とは別に扱う。
