Abrir en el navegador Añadir a Chrome

Gratuito y de código abierto (MIT), con el código en GitHub. La versión para navegador no necesita instalación ni cuenta, y el editor está disponible en siete idiomas, entre ellos español, inglés, portugués, japonés, coreano y chino.

Captura, anota y guarda.

Harie cubre todo, desde la primera captura hasta el archivo guardado.

  1. 1

    Capturar

    Con la extensión de Chrome puedes capturar la página en la que estás y abrirla directamente en el editor. Elige el área visible, una zona que arrastres o un solo elemento, como un botón.

  2. 2

    Anotar

    Explica con recuadros, flechas, números, globos de texto y focos. Dile a Harie qué quieres explicar y la IA te propone recuadros numerados con sus textos.

  3. 3

    Guardar

    Harie guarda un JPEG o PNG normal. Puedes pegarlo tal cual en tu centro de ayuda, y quien lo abra más adelante podrá seguir editando las anotaciones.

Abre una captura, dibuja recuadros y pulsa «Añadir números y globos» para añadir los números y los globos de una vez. Después solo tienes que escribir el texto de los globos.

Abre una imagen guardada con Harie y sus recuadros y globos vuelven tal cual. Cuando cambie el texto de la interfaz, haz doble clic en el globo, corrígelo y vuelve a guardar.

Selecciona nombres y direcciones de correo y sustitúyelos por texto ficticio. La pantalla conserva su aspecto, así que se sigue entendiendo qué es, y los valores originales no quedan en la imagen.

Por qué sigue siendo editable

Una imagen contiene la pantalla original y las anotaciones.

Una imagen guardada con Harie lleva, junto a lo que ves, la captura original y los datos de las anotaciones. Otras aplicaciones y navegadores simplemente muestran una imagen normal.

Ábrela en Harie y podrás mover o reescribir cada recuadro y cada texto. No hace falta guardar un archivo de proyecto aparte, y quien reciba la imagen puede abrirla y corregirla.

Al volver a guardar, la captura original nunca se recomprime, así que la calidad se mantiene por muchas veces que la edites. La especificación del formato es pública (en japonés).

Anotaciones sugeridas

Escribe algo como «Explica cómo configurar las notificaciones de Slack» y la IA propondrá dónde van los recuadros y qué dicen. Puedes aceptar, rechazar o editar cada sugerencia. En las capturas de la extensión de Chrome, los recuadros se ajustan a los elementos reales de la página.

Conéctate con OpenRouter o usa tu propia clave de API de Anthropic. Harie siempre pregunta antes de enviar una imagen, y tu clave nunca sale de este navegador.

Edita desde Claude (Skill y MCP)

Añade la Skill de Harie a claude.ai, adjunta una captura al chat y pide a Claude que añada o corrija anotaciones. Con Claude Code o Claude Desktop en tu ordenador, el servidor @harie/mcp trabaja directamente con las imágenes de una carpeta. Cuando cambia el texto de la interfaz, puedes actualizar de una vez todas las imágenes afectadas.

Datos personales

Quita los datos personales y conserva el sentido.

Sustituye nombres, direcciones de correo y números de teléfono por valores ficticios. A diferencia de un desenfoque, así los lectores siguen entendiendo qué tipo de pantalla están viendo. Si lo prefieres, también tienes relleno, mosaico y desenfoque.

La ocultación se aplica a la imagen original, así que no se puede deshacer. Eso también significa que los valores originales no viajan con el archivo cuando lo compartes.

Integraciones con IA

Pide a la IA que anote por ti.

Solo tienes que pedírselo a Claude, y añadirá anotaciones a tus imágenes de Harie o corregirá su texto. Usa la Skill en claude.ai y en sesiones en la nube, o el servidor MCP con Claude Code, Claude Desktop y la app de escritorio de ChatGPT en tu ordenador. De cualquier forma, obtienes el mismo archivo.

El enmascaramiento de datos personales no se puede deshacer, así que Harie solo lo guarda cuando lo confirmas.

Funciona en los chats y proyectos de claude.ai, y en Claude Code on the web. No tienes que instalar nada en tu ordenador: adjunta una captura al chat y pide las anotaciones.

  1. Descarga harie.skill desde las releases de GitHub.
  2. En claude.ai, ve a Configuración → Capacidades y activa Ejecución de código y creación de archivos.
  3. En la misma página, sube harie.skill en Skills.

Las Skills que añadas a tu cuenta también funcionan en Claude Code on the web. En Claude Code, también puedes instalarla como plugin con estos comandos.

/plugin marketplace add hosshan/harie
/plugin install harie@harie
  • La Skill obtiene @harie/mcp de npm y lo ejecuta dentro de la conversación, así que el dibujo y el guardado funcionan exactamente igual que con MCP.
  • En los planes Team y Enterprise, un administrador debe permitir las Skills y la ejecución de código.
Guía de instalación detallada (GitHub, en japonés)

Registra el servidor @harie/mcp en una app de tu ordenador, y podrá abrir y corregir imágenes de una carpeta de tu equipo.

Ejecuta este comando en tu terminal.

claude mcp add harie -- npx -y @harie/mcp --root ~/Pictures/guides

Añade esto a claude_desktop_config.json y reinicia Claude Desktop. Sustituye la carpeta por tu propia ruta.

{
  "mcpServers": {
    "harie": {
      "command": "npx",
      "args": ["-y", "@harie/mcp", "--root", "/Users/you/Pictures/guides"]
    }
  }
}

Funciona en la aplicación de escritorio de ChatGPT. Añade esto a ~/.codex/config.toml y reinicia la aplicación. Esta configuración se comparte con Codex CLI y la extensión para IDE. También puedes añadir el mismo comando como servidor STDIO en la sección de servidores MCP de los ajustes de la aplicación.

[mcp_servers.harie]
command = "npx"
args = ["-y", "@harie/mcp", "--root", "/Users/you/Pictures/guides"]

ChatGPT en la web no puede conectarse a servidores MCP que se ejecutan en tu ordenador.

  • Requiere Node.js 22 o posterior. El servidor se ejecuta desde npm con npx, así que no hay nada más que instalar.
  • Apunta --root a la carpeta que contiene tus imágenes. El servidor solo puede leer y escribir dentro de esa carpeta.

Preguntas frecuentes

¿Qué es Harie?

Harie es una herramienta para añadir recuadros, números, globos de texto y flechas a las capturas de pantalla de la documentación de ayuda y las guías de uso de un SaaS. Guarda un JPEG o PNG normal y, cuando vuelves a abrir esa imagen en Harie, todas las anotaciones siguen siendo editables.

¿Otras aplicaciones y sitios web pueden mostrar las imágenes guardadas?

Sí. Harie guarda un JPEG o PNG normal, así que puedes pegarlo tal cual en páginas de ayuda, chats o documentos. La captura original y los datos de las anotaciones van en los metadatos de la imagen, y solo Harie los usa.

¿Puedo editar imágenes de guía que hizo otra persona?

Sí, siempre que se hayan guardado con Harie. Abre en Harie la imagen que recibiste y podrás mover o reescribir cada recuadro y cada nota. No necesitas un archivo de proyecto ni una cuenta.

¿En qué se diferencia Harie de herramientas como Snagit o Scribe?

La imagen exportada sigue siendo editable. Las aplicaciones de captura guardan las anotaciones editables en sus propios archivos de proyecto, que se quedan con quien los creó. Los servicios para crear guías solo permiten editar dentro de sus propias cuentas. Harie guarda la captura original y las anotaciones dentro del JPEG o PNG, así que cualquiera que tenga la imagen de tu página de ayuda puede abrirla y editarla. Harie no genera guías paso a paso a partir de acciones grabadas.

¿Harie cuesta algo?

No. Harie es gratuito, de código abierto con licencia MIT y no requiere registro. Solo las sugerencias de IA necesitan tu propia clave de API de Anthropic o una cuenta de OpenRouter, y pagas a esos servicios por lo que uses.

¿Mis imágenes se envían a un servidor?

No. Las imágenes se procesan en tu navegador o en tu dispositivo, y el desarrollador nunca las recibe. Solo cuando usas las funciones de IA, Harie envía la imagen, después de preguntarte, directamente a la API de Claude de Anthropic (a través de OpenRouter si te conectaste con OpenRouter).

¿Puedo ocultar datos personales en una captura?

Sí. Puedes sustituir nombres, direcciones de correo y números de teléfono por valores ficticios, o usar relleno, mosaico o desenfoque. El cambio se aplica a la imagen original, así que no se puede deshacer, y los valores originales no quedan en el archivo que compartes.

¿Dónde puedo usar Harie?

Hay un editor web que funciona en el navegador, una extensión de Chrome que captura la página en la que estás, una Skill para claude.ai y otros entornos, y un servidor MCP para agentes de IA. La app de escritorio para macOS y Windows aún no se distribuye, pero puedes compilarla desde el código fuente.

¿Los agentes de IA como Claude pueden añadir anotaciones?

Sí. Añade la Skill (harie.skill) a claude.ai y Claude podrá anotar las capturas que adjuntes al chat. Registra el servidor MCP @harie/mcp en Claude Code o Claude Desktop y podrá abrir imágenes de la carpeta que elijas, añadir anotaciones y actualizar el texto.
